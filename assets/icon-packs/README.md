# Onion icon packs

TreeFrogUI ships the ten icon packs listed by the official Onion theme catalog.
The catalog does not expose download counters, so these are the complete
curated standalone set rather than an invented "most downloaded" ranking.

TreeFrogUI only maps filenames and resizes the supplied PNGs to fit its System
View. No icons are redrawn. The original creator names and upstream notes are
retained below and inside each pack where supplied.
