# Независимая загрузка: исследование контейнеров и загрузчика

Цель: получить проверенное описание преобразования SD boot-образов и путь
загрузки собственного ядра без предварительного старта штатного Linux.

Рабочие stock boot-файлы/NOR на стадии исследования не меняются.
Источники: исходные контейнеры в `analysis/card2_files/cubegm_enc`,
точные ELF из `/tmp/cubegm`, свежий NOR и BootROM в `analysis/kmem`,
проверенные дампы RAM AVP и живое чтение через NSH `xd`.

Старые отрицательные поиски AES/S-box или отсутствие открытого `/dev/dsc`
не доказывают отсутствие расшифровки на ранних стадиях загрузки.
