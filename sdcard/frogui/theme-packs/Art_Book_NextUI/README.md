# Art Book NextUI

Background artwork adapted for TreeFrogUI from
[Leviathanium/NextUI-Themes](https://github.com/Leviathanium/NextUI-Themes/tree/main/Catalog/Themes/ArtBookNextUI.theme).

The upstream 1024×768 system wallpapers are center-cropped and converted to
854×480 JPEGs for the supported TreeFrogUI panels. The original pack remains
available as **Art Book Next**; this is the updated NextUI resource set.
