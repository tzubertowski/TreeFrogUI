# PrettyTreeFrog

An original TreeFrogUI background pack with dark, muted rainforest scenes and
matching system-specific artwork for the supported ROM-folder aliases.

The pack is rendered at the native SF3000/SF3500 panel size, 854x480, using
optimized RGB JPEGs. It includes dedicated screen backgrounds for the main
menu, settings, recents, favourites, and ports views.

The artwork is released under CC0 1.0 Universal. See `LICENSE` for the
dedication and reuse terms.
