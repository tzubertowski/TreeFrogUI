# Changelog

Permanent project history. Per-release announcements are kept separately in
[`release-notes.md`](release-notes.md).

## 2026-11-11

- **v1.9.0_e prerelease:** Added optional per-style JSON profiles for FrogUI,
  saved user overrides across style switches, the `ignoreOverrides` profile
  option, and ProMinimal's compact settings and Apps-in-Settings layout. Added
  per-style controls for settings layout, pills, fonts, quick resume,
  auto-save/load, backgrounds, recents, battery indicators, and Apps placement.
- **v1.9.0_f prerelease:** Set ProMinimal to start in Recents, restored the
  previous Alium Nunito size 23 default for the other styles, and migrated
  existing Start in Recents opt-ins into the user override settings.

## 2026-10-27

- **v1.8.0_t prerelease:** Added ScummVM based on [Synaps33's FroggyScummvm](https://github.com/Synaps33/FroggyScummvm); restored missing system artwork and translations; and reduced PicoArch audio popping under heavy load.
- **Ports Collection:** Ports are released separately from TreeFrogUI. Get the
  latest archive from the [Ports Collection releases](https://github.com/tzubertowski/TreeFrogUI_PortsCollection/releases/latest)
  or install them through the TreeFrogUI Installer's **Install ports** option.
  See the [Ports installation guide](docs/cores/ports.md).

## 2026-10-28

- **v1.8.0_u prerelease:** Keep system navigation responsive during background-image loading, sort systems by their displayed friendly names when enabled, and keep the pill highlight in step with rapid scrolling.

## 2026-10-29

- **v1.8.0 stable:** Promoted the tested v1.8.0_u build with its accumulated core, ports, FrogUI, audio, artwork, translation, and device-support updates.
- **v1.9.0_a prerelease:** Added the simulated clock settings, manual USB time sync, configurable per-boot time bump, and date/time documentation.

## 2026-10-30

- **v1.9.0_b prerelease:** Added Synaps33 (Sajnaps)'s EPUB-only FroggyReader Libretro core to Apps, with a 640×480 renderer and bundled sample library.
- Added PDF zoom and pan controls to the standalone Ebook reader.
