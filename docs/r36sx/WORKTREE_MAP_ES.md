# Mapa de carpetas de trabajo — TreeFrogUI R36SX

## Fuente de verdad local para GitHub

La carpeta que se usa para commits, ramas y push hacia GitHub es:

```text
D:\R36S\TreeFrogUI-github
```

En WSL:

```text
/mnt/d/R36S/TreeFrogUI-github
```

Este clon tiene `.git`, `origin=https://github.com/ozkaoz/treefrog-ui.git` y una rama remota ya publicada.

## Carpetas de referencia que no son el clon activo

```text
D:\R36S\TreeFrogUI\treefrog-ui-main
```

Es una extracción de ZIP/source snapshot. No fue la carpeta usada para `git push`. Puede servir como referencia, pero no debe confundirse con el clon activo.

## Regla de seguridad

No eliminar ninguna carpeta estable hasta que exista un ZIP congelado con fecha, versión, SHA o nota clara. Para cambios de código, trabajar siempre desde una rama nueva en `TreeFrogUI-github`.
