# TreeFrogUI image viewer

Standalone viewer for images launched from `roms/images/`. It uses HCRTOS's
native `libffplayer` picture decoder and hardware video plane, and reads colors
and button mappings from TreeFrogUI's generated skin and keymap files.

Controls: Left/Right or L1/R1 changes image, A switches Fit/Fill, X rotates,
Y toggles the HUD, and B/Select exits.
